# md2pdf

用 Chrome headless 排版 + PyMuPDF 后处理，把 Markdown 转成正式 PDF。

## 安装

把整个 `skill/` 目录（含本文件）放到 `~/.claude/skills/md2pdf/`，或项目内的 `.claude/skills/md2pdf/`。

工具本体 `md2pdf.py` 需要能被找到。建议把仓库 clone 到固定位置，在下面的命令里用绝对路径调用。

依赖：

```bash
pip install markdown pymupdf pyyaml
```

外加本机的 Chrome 或 Edge（自动探测，找不到用 `--browser` 指定）。

## 基本用法

```bash
python /path/to/md2pdf.py 文档.md
```

输出同目录同名 `.pdf`。

## 工作流程

1. **先读源文档**，判断它属于哪类（见下面「场景配方」）
2. **写 front-matter**（在 `.md` 最开头，必须是第一行）
3. **跑命令**
4. **读自检输出**——有 `[自检]` 报错必须处理，提示可以判断后忽略
5. 把结果告诉用户，说明页数和自检状态

## 场景配方

选好配方直接套，不要每次从零配。

### 正式文件（技术方案、调研报告、对外交付件）

```yaml
---
title: |
  项目名称
  文件类型
subtitle: V1.0 | 依据 ×× 编写
kicker: PROJECT NAME IN ENGLISH
theme: navy
meta:
  项目: xxx
  编制单位: xxx
  版本日期: 2026-09-20
notice: |
  **版本提示**
  本文依据 ×× 编写。
cover_footer: 单位名 · 文件密级
header_left: 项目名 · 文件类型
footer_left: 密级标识
---
```

### 会议纪要、短通知（2-5 页）

```bash
python md2pdf.py 纪要.md --no-cover --no-break
```

短文档不要封面、不要每章分页，否则一章半页也占一整页。

### 宽表格清单（价格表、参数对照表）

```bash
python md2pdf.py 参数表.md --landscape --font-size 9
```

列还塞不下就在 front-matter 里 `table_font_size: 7.8`，再不行拆表。

### 章节很多的手册

```bash
python md2pdf.py 手册.md --toc-depth 2
```

## 样式选择

有 7 种内置样式，用 `-s 名称` 或 front-matter 里的 `style: 名称` 选择，中英文名都认：

| 样式 | 中文名 | 适合 |
|---|---|---|
| `default` | 默认 | 通用正式文档。**不指定就是它** |
| `gov` | 公文 | 给领导、机关、上级单位的汇报材料 |
| `steel` | 钢蓝 | 正式报送文件，现代风格，封面带签字栏 |
| `graybl` | 灰蓝 | 正式技术文件，稳重风格，封面带签字栏 |
| `consult` | 咨询 | 给客户的汇报、方案比选 |
| `intl` | 国际 | 外方客户、中英双语文件 |
| `brief` | 简报 | 领导简报、决策汇报 |

**导出前先问用户选哪种样式**，除非用户已经指定，或者之前说过偏好。拿不准就用 `default`。

- 样式只提供默认值，front-matter 里的其他配置会覆盖它
- `gov` 默认章节连排（不每章分页），字号 13.5pt，适合篇幅短的汇报
- 封面签字栏：`signoff: true` 加「编制 / 审核 / 批准」，`signoff: false` 去掉，也可以给列表自定义栏目
- 目录引导点：`default` `gov` `steel` `graybl` 默认有；其余样式用 `toc_leader: true` 或 `--toc-leader` 打开，`toc_leader: false` 关闭
- `--list-styles` 列出全部样式

另有 `--theme` 只换配色、不换版式：`navy` `slate` `forest` `crimson` `ink`。

## 关键配置速查

完整表见仓库 README 第 3 章，最常用的：

| 键 | 说明 |
|---|---|
| `theme` | navy / slate / forest / crimson / ink |
| `toc_depth` | 1 只收 `##`；2 收 `##` + `###` |
| `break_before_h2` | 每章另起页，默认 true，**短文档设 false** |
| `table_font_size` | 默认 8.6，列多调到 7.5~8 |
| `landscape` | 横向，宽表格用 |
| `header_left` / `footer_left` | 页眉页脚左侧固定文字 |
| `extra_css` | 追加 CSS，覆盖内置样式 |

**页眉右侧不用配**，它自动显示当前章名。

## 写 Markdown 的规则

- `#` 只写一个，会被摘掉当文档标题（封面已有）
- `##` = 章，默认另起一页，进目录
- `###` = 节，左侧竖色条
- `>` 引用块 → 橙黄提示框，放警告和重点结论
- ` ``` ` 代码块 → 浅灰底，中文流程图用它画比 Mermaid 省事
- `*斜体*` → 不是斜体，是底纹高亮（中文斜体难看，改掉了）

## 必须避开的坑

1. **front-matter 必须在第一行**，前面不能有空行
2. **YAML 里带冒号的值要加引号**：`金额: "US$ 100: 含税"`
3. **`---` 分隔线不要紧挨 `##` 标题**——会造出空白页（脚本已自动处理，但别主动写）
4. **表格每行 `|` 数量必须一致**——少一格不报错，直接静默串列。这是最容易漏的错误，写完数一遍
5. **中文表格统一左对齐**，不要用 `---:` 右对齐，两列之间会拉开视觉裂缝

## 读自检输出

出片后自动跑，输出形如：

```
[自检] 2 项提示：
   - p19 内容稀疏（245 字）
```

| 级别 | 含义 | 怎么办 |
|---|---|---|
| **错误** | 空白页、机器残渣（`@@H` `{{`） | **必须修**。空白页查 `---` 紧挨标题；机器残渣是 bug，报 issue |
| 提示 | 稀疏页、草稿标记、内容溢出、目录定位失败 | 判断后决定。稀疏页常是章节末留白，正常 |

## 自检查不了的四类

**这四类是实际返工的主要来源，必须另外核对**——如果用户是在做对外文件，主动提醒：

- 表格列数是否一致
- 编号是否连续（M1、M2、M3 有没有断号）
- 关键数字全文口径是否一致（改了一处漏了另一处）
- 正文与配套 Excel 是否对得上

仓库 README 第 11 章有一份 12 条的定稿检查清单，对外交付的文件建议过一遍。

## 排版出问题时

**不要在 CSS 里猜。** 用 `--keep` 保留中间 HTML 直接看：

```bash
python md2pdf.py 文档.md --keep --preview 1 2 10
```

`--keep` 会打印中间目录，里面的 `_m2p_p1.html` 能用浏览器打开，F12 实时调样式，调好了抄回 `extra_css`。

## 常见故障

| 症状 | 解法 |
|---|---|
| 报「浏览器未生成 PDF」 | `--browser "完整路径"` |
| 表格右边被切掉 | `table_font_size: 7.8` → `landscape: true` → 拆表 |
| 中文变方块（页眉） | 指定 `stamp_font: /路径/字体.ttc` |
| 一章半页却占整页 | 加 `--no-break` |
| front-matter 没生效 | 检查是不是在第一行，YAML 语法对不对 |
| 跑得慢 | 正常，50 页约 20~40 秒（每遍要起一次浏览器） |
